# Surendar — Personal Portfolio

Welcome to the personal developer portfolio of **Surendar** — Full Stack Developer.

- **GitHub Repository**: [Surendar.space](https://github.com/SurendarNehru/Surendar.space.io)
- **Live Domain**: [surendar.space](https://surendarnehru.github.io/Surendar.space.io/)

## Features
- **Arcade Pixel Game Font System**: Custom retro pixel styling (`Pixelify Sans`, `Press Start 2P`, `Silkscreen`, `VT323`).
- **Looping Typewriter Hero**: Smooth infinite typewriter effect for **SURENDAR** and **FULL STACK DEVELOPER**.
- **Interactive Space Galaxy & Starfield**: 3D particle Canvas and WebGL interactive galaxy background.
- **Glassmorphism UI**: High-definition glass surfaces, smooth micro-interactions, and dark cosmic aesthetics.
